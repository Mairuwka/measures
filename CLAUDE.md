# Симулятор мэра — макеты интерфейса

Командная экономическая игра для школьников 8–11 классов: шесть команд-комитетов управляют одним городом (Петербург, пиксель-арт). В этом репозитории — всё, что нужно для работы с макетами в Figma: карта файла, правила вёрстки, снимки ТЗ, иллюстрации и скрипты.

**Перед любой задачей по макетам прочитай [docs/README.md](docs/README.md)** — там оглавление вики. Минимум для старта:

- [docs/figma.md](docs/figma.md) — какой Figma-файл, страницы, секции, ID всех экранов, эталоны и UI-кит.
- [docs/figma-rules.md](docs/figma-rules.md) — правила, по которым принимаются экраны (дизайнер проверяет каждую мелочь).
- [docs/figma-howto.md](docs/figma-howto.md) — как править файл через Figma MCP: сессия, страницы, шрифт Pixel Code, загрузка картинок, аудит.
- [docs/spec/README.md](docs/spec/README.md) — ТЗ: оглавление, ссылки на Google Docs и локальные снимки.
- [docs/illustrations.md](docs/illustrations.md) — иллюстрации: где лежат, что куда ставится.
- [docs/text-wrapping.md](docs/text-wrapping.md) — правила переносов строк (и для Figma, и для разработки).

## Коротко о главном

- Figma-файл: `C7RaBUXYvu4972DadQ8qsW`. Рабочая страница — «Экраны для согласования» (`2012:87`), эталоны и UI-кит — страница «1» (`0:1`, секция `components` = `54:81`), служебная — «_build · служебная» (`2040:87`).
- Экраны собираются из эталонов и компонентов кита 1:1, менять можно только контент. Каждое состояние (hover, pressed, choosen…) сверять с одноимённым компонентом кита.
- Шрифт Pixel Code через MCP не загружается: изменённые надписи Pixel Code собираются из контуров глифов (`L.px` со служебной страницы), см. figma-howto.
- После каждой правки — прогнать `audit.js` со служебной страницы и посмотреть скриншоты. Дефекты находить самому, не ждать, пока их найдёт дизайнер.
- Тяжёлые файлы (иллюстрации, GIF) лежат в `assets/` и в git не попадают (`.gitignore`); исходники — в Google Drive, ссылки в docs/illustrations.md.
- Язык общения и макетов — русский.
