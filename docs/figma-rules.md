# Правила вёрстки экранов

Всё, что дизайнер отмечал в правках 06–07.11.2026. Экран считается готовым, только если выполнены все пункты. Свериться с этим списком нужно до того, как показывать результат.

## Общее

- **Собирать из эталонов и кита 1:1.** Экраны клонируются из эталонов на странице «1» (секции «экран s-08», «экран s-01», «модалки p-07/p-11»), элементы — из `components` (`54:81`). Отступы, размеры, шрифты и режимы auto-layout не меняются, меняется только контент. Не добавлять в компоненты кита лишних строк и бейджей.
- **Состояния — строго по киту.** hover, pressed, choosen, error, disabled берутся из одноимённого компонента, включая свечение (размер и смещение прямоугольника с `LAYER_BLUR`), обводку и затемнение картинки. Примеры:
  - Сommittee_card/Team_card: hover — свечение шире карточки (−6/−6 у комитета 376×310, −6/−7 у команды 376×278), pressed — свечение ровно по карточке, choosen — без свечения, с розовой обводкой и затемнением 65 %.
  - Chip_primary/pressed — свечение по ширине чипа, `y = 2`, высота = высота чипа − 4.
  - Badge/primary со свечением — прямоугольник свечения ровно по размеру бейджа.
  - Свечение ползунка слайдера — ровно под ползунком (`thumb`).
- **Высоты в одном ряду одинаковые.** Карточки комитетов всегда 296 (заголовок фиксированной высоты 72, по центру), карточки команд — 260.
- **Шкала отступов 4 px**, отступы групп 24/40, радиусы 0/20/32/40/80/100/full («Общие правила» `54:19959`).
- **Нижняя панель** (`control_panel`) — `SPACE_BETWEEN`, панель ходов по содержимому. Если панель ходов растянута (одиночная игра, S-10, съезд), неактивные этапы делят место поровну (`FILL`), активный этап — 250.
- **Никаких служебных пометок внутри макета.** Пояснения — только во фрейме `annotation · …` под экраном.
- **Сквозные данные согласованы:** номера раундов, команды, суммы. Например, если на S-07 идёт раунд 3, то P-14 пишет «Раунд 3 не будет оценён», а в документообороте — записи «Р3». Список команд — в [figma.md](figma.md).

## Корешок поп-апа (`upper_group_close` → `pattenr_form`)

- Одна форма для всех: путь корешка системных окон (W = 408: скругление 36,77, скос 72,38, плечо 143,39). Форму **никогда не растягивать по ширине**: меняется только длина прямого участка, точки скоса сдвигаются. Скрипт — `figma-scripts/tabs.js`.
- Ширина по содержимому: текст на `x = 69`; с кнопкой ✕ `W = 69 + текст + 16 + 32 + 34`, кнопка на `69 + текст + 16`; без кнопки `W = 69 + текст + 35`. Ширина формы `S = W + 3`, правый край вкладки не двигается.
- Полосатый узор внутри корешка — тот же вектор, что в теле окна (4049×2343, 9 %), выровненный с ним.
- Если название не влезает в узкое окно — в корешке тип окна (как «случайное событие» в P-12), а полное название заголовком в контенте.
- У корешков с логотипом («симулятор мэра») своя форма, их не трогать.

## Поп-апы

- **Скроллбар** — как в ките: группа `slider` в `modal_container` (абсолютная), бегунок 14×29 `#E94785` на `y = 68`, дорожка 4 px `#172827` от `y + 6` до нижней панели окна − 18. `x = ширина контейнера − 42` (для окна 560 — 516). Есть только там, где контент длиннее видимой части. Скрипт — `figma-scripts/scrollbars.js`.
- Списки вне поп-апов (документооборот, «Входящие от комитетов») — тот же скроллбар, но дорожка `#4C5152`, иначе её не видно на тёмной панели; справа у списка отступ 26.
- **Затемнение:** P-01, P-02, P-04, P-13, P-14, P-15 — слой `overlay` #000 65 % прямо под окном (над всем интерфейсом). P-16 — решено оставить без затемнения (окно сида целиком перекрывает окно никнейма). P-05…P-12, P-17, P-18 — без затемнения.
- **График по раундам** (`UI-12 · Round_graph`) растянут на ширину блока (FILL, в окне 800 — 712), как в эталоне `122:1359`: сетка `lines` 602, кривая 594. В режиме HUG рамка сжимается до 264, а кривая вылезает за подложку; `audit.js` этого не ловит, т. к. `Graph` не обрезает содержимое.
- **Главный показатель в P-10** выглядит так же, как строки «из чего складывается» (`metUp`/`metDown`: подпись с единицей, значение, бейдж изменения). Полное название — в подписи строки, дублирующий заголовок не нужен.
- **Строки показателей** (`metN` / `metUp` / `metDown`): одно значение — одна строка. Никаких «A · B · C» в одной строке: разбивать на отдельные строки с подписью-группой сверху (как «Свободные помещения» в И-06, «Ветхий фонд» в И-19).
- Подписи строк переносятся по правилам [text-wrapping.md](text-wrapping.md). Если строка всё равно переносится некрасиво или не помещается — менять формулировку («Не хватает…» вместо «Нужно достроить…»), а не сокращать слова.
- Названия пишутся целиком, без сокращений вроде «ЦСИ», «пром.», «ОТ», «тур.» — даже если подпись уходит на вторую строку.
- **Окно по содержимому.** Если контент короче максимальной высоты окна (650), высота `pattern` = высота `modal_container`, без пустоты снизу (P-11.02 было 561 при содержимом 449). Нижний отступ контейнера 24 не должен «съедаться» дополнительной строкой: при новой строке (ошибка в P-02.e) контейнер растёт, окно остаётся по центру экрана.
- **Вкладки (Chip_primary) в окне** — переключаются строго по киту: у нажатой — свечение `Rectangle 24514` (`y = 2`, высота чипа − 4), заливка #232727, обводка #FD3286 2,2, текст #E3E3E3 с розовой тенью; у обычной — без свечения, заливка #172827, текст #F2F2F2 с серой тенью #9D9D9D.
- **Подсказка при наведении** (ссылка, иконка без «?») — реплика `Dialog_window` из кита (вариант с текстом Inter): отступы 12, обводка 2 #4C5152, радиус 20, полосатый узор; хвостик лежит под окном и указывает на элемент (подсказка под элементом — хвостик сверху слева). Ширина — по самой длинной строке. Элемент в состоянии hover по киту. Пример — P-02.h.

## Числа на экранах

- **Никаких заглушек.** Значения строк, вкладок и графиков согласуются по формулам ТЗ: части в сумме дают целое, доли — отношение показанных чисел, «прошлый раунд» — из бейджа изменения. Связки и опорные числа — в [figma.md](figma.md), раздел «Числа показателей», и в шапке `figma-scripts/review-values.js`.
- Тип строки — по изменению: нет изменения → `metN` (без бейджа), рост → `metUp`, падение → `metDown`. Нормы, индексируемые инфляцией (цена гектара, базовые цены), умножаются на коэффициент инфляции раунда.
- Меняя число, менять и связанные с ним на других экранах (панель бюджета комитета, итог/остаток инструмента, P-10, P-11, И-xx).

## Текст

- **Никаких разделителей « · »** на экранах: отдельные строки, перенос строки или естественная фраза («съезд комитетов по итогам раунда 3», «наблюдение за комитетом по транспорту»).
- «приемная» — через «е».
- Единицы соответствуют смыслу: земля — в кв. м, средняя ЗП — на одного жителя (не триллионы).
- Пояснения к числам — двухчастный бейдж как в ките (значение розовым + подпись белым): «+2 % сезонность».

## Блоки экранов ведущего и съезда

- **Лидерборд (BLK-02) и документооборот (BLK-03)** — каждая строка отдельной плашкой (#172827) с зазором 12, как `row_group` / `doc_flow_group` в ките; карточки документооборота с обводкой 2 px `#4C5152`. Строки лежат на подложке как у тела поп-апа: заливка #202E30, обводка 4 px #303E40 внутрь, радиус 40, размытие фона 6,2, полосатый узор (вектор 4049×2343, 9 %, слой `pattern · полосы`), внутренний отступ 24, заголовок блока по центру. Документооборот заканчивается за 24 px до нижней панели (высота блока 811). На S-11 так же оформлены «итоговый лидерборд», «Итоги» и «Графики», но с отступом 12, чтобы панели не наезжали на BLK-01.
- Своя команда: строка лидерборда `Leaderboard_row/up` (розовая), записи документооборота — розовый тег `Doc_flow_ur` со свечением.
- Строка документооборота: два состояния — однострочная (высота по содержимому, всё по центру) и 2–3 строки (бейджи у первой строки). Текст не обрезается многоточием.
- «Пауза» у ведущего во время P-17 — disabled.

## Контроль качества

1. Прогнать `audit.js` (как — в [figma-howto.md](figma-howto.md)). Допустимые старые замечания: отступы `Badge_small` (12 вместо 8) и `Button_primary/disabled`, наложение реплики на S-10.
2. Скриншоты каждого изменённого экрана, крупно — проблемные места (корешки, тени, переносы).
3. Проверить вариант того же элемента на всех экранах, а не только на одном, на который указали: дизайнер ждёт исправления «во всех таких местах».
