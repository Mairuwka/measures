## **Общие правила**

|  |  |
| :-: | :-: |
| \*\*ID\*\* | \*\*Правило\*\* |
| R-01 | \*\*Какое значение читает формула.\*\* Формула берёт последнее посчитанное значение показателя на момент расчёта. Градостроительство ходит четвертым и видит Население после хода миграции и количество бизнесов после хода бизнеса. Явная пометка «(раунд t−1)» – итог прошлого раунда, не меняется в течение текущего. В раунде 1 вместо t−1 используются стартовые значения. |
| R-02 | \*\*Когда считается ход.\*\* Расчёт хода выполняется сразу после завершения хода, затем пересчёт города (R-08). |
| R-03 | \*\*Время хода.\*\* 1,5 минуты по умолчанию (меняется на экране настройки партии у ведущего). |
| R-04 | \*\*«Применить» окончательно.\*\* Деньги списываются, значение записывается, в «Документооборот» добавляется строка. Примененное решение в этом ходу нельзя уменьшить или отменить, можно докупить сверх него: ручка двигается только вверх. |
| R-05 | \*\*Таймер хода истёк.\*\* Непримененные изменения в открытых поп-апах сбрасываются, примененное остаётся. |
| R-06.1 | \*\*Бюджет хода общий для всех инструментов комитета.\*\* Доступный остаток = бюджет комитета на начало хода − стоимость решений, уже примененных в этом ходу − стоимость текущих значений инструментов, которые оплачиваются в конце хода и не имеют кнопки «Применить». Значения, которые выбраны, но не применены, остаток не уменьшают. |
| R-06.2 | \*\*Максимум инструмента.\*\* Нельзя выбрать значение инструмента дороже, чем позволяет остаток. Если в одном окне несколько инструментов, их выбранные значения считаются вместе: общая стоимость не может превышать остаток. |
| R-06.3 | \*\*Остаток уменьшился.\*\* Если остаток уменьшился из-за действия в другом окне, максимумы во всех открытых окнах пересчитываются. Если выбранные значения перестали помещаться в остаток, игра сама уменьшает их до допустимых: сначала значение, измененное последним, затем предыдущие, пока общая стоимость не поместится. Значения не уменьшаются ниже уже примененных в этом ходу (R-04). Игрок видит подсказку, что выбранное значение уменьшено, ошибка не показывается. |
| R-06.4 | \*\*«Недостаточно бюджета» показывается, когда:\*\* 1) игрок сам пытается выбрать значение дороже остатка (там, где шкала шире доступного максимума); 2) игрок меняет параметр, от которого зависит цена (например, качество), и стоимость выбранного значения становится больше остатка. Выбранное значение при этом не меняется, и применить решение нельзя, пока игрок сам его не уменьшит; 3) остатка не хватает даже на минимальную единицу инструмента. |
| R-06.5 | \*\*Инструменты с оплатой по факту в конце хода.\*\* Максимум считается по текущим данным, примененное значение остаток не уменьшает, стоимость списывается по завершении хода по фактическим данным; при нехватке значение урезается пропорционально. |
| R-07 | \*\*Слайдеры на игровом экране (SL-xx).\*\* Без «Применить», в течение хода двигаются в обе стороны, значение фиксируется, а стоимость списывается по завершении хода. Платный слайдер уменьшает остаток своим текущим положением сразу. |
| R-08 | \*\*Пересчёт города\*\* после хода каждого комитета, в START каждого раунда (в раунде 1 – после стартового снимка S0, R-GEN-04) и итоговый в END. Идемпотентен: значения t считаются от сохраненных итогов t−1 и решений раунда; стоки (площади, территория, ветхий фонд) не прибавляются повторно. «Применить» показатели не меняет. Иконка изменения KPI сравнивает с итогом прошлого раунда, точка графика UI-12 – только по итогу раунда. Освоение миграционного потенциала фиксируется в расчёте хода миграции по пропускной способности из пересчёта START |

  

## **Правила комитета по градостроительству**

|  |  |
| :-: | :-: |
| R-URB-01 | \*\*Земля – общий ресурс хода\*\*, как бюджет. Доступная земля = Свободная для застройки площадь на начало хода + земля, выкупленная и примененная в этом ходу − земля, уже переданная (примененная) в этом ходу под жилую и бизнес-застройку. Все 8 слайдеров И-11 и И-12 делят доступную землю по правилам R-06.2–R-06.4 (максимум, автоматическое опускание, «недостаточно земли»). Выкупленная в этом ходу земля доступна для передачи сразу после «Применить» в И-10. |
| R-URB-02 | \*\*Ветхий фонд – общий ресурс поп-апа И-19.\*\* Ветхая площадь низкоэтажной застройки одновременно ограничивает реконструкцию этого типа и передачу объектов комитету по образованию: выставленное в одном уменьшает максимум другого, опускание – по R-06.3. |
| R-URB-03 | \*\*Действие субсидии до следующего хода градостроя.\*\* Показатель субсидирования, зафиксированный в ходе раунда t, используется во всех пересчётах до расчёта хода градостроя в раунде t+1 (так же, как мероприятия образования. Ручка SL-06 в START раунда t+1 возвращается в 0%; если её не поднять, после хода градостроя t+1 субсидия = 0. |

  

## **Место комитета в раунде**

«Применить» в поп-апах только фиксирует значения инструментов и списывает деньги. Сразу после хода выполняется расчёт хода (площади, цена метра, доступность, KPI), затем пересчёт города. Комитеты, которые ходят позже (транспорт, туризм), и комитеты следующего раунда (миграция, бизнес, образование) работают уже с новыми площадями и ценами (R-01, R-02, R-08).

|  |  |  |
| :-: | :-: | :-: |
| \*\*Фаза\*\* | \*\*Что происходит\*\* | \*\*Формулы\*\* |
| START | Срабатывает событие (с раунда 2), затем считаются инфляция раунда и Коэффициент инфляции (t) Комитет получает бюджет. Часть жилого фонда каждого типа уходит в ветхий фонд (0,05% от площади t−1). Ручка SL-06 возвращается в 0%. Затем пересчёт города, в том числе в раунде 1 (после стартового снимка S0, R-GEN-04). | F-URB-05, F-URB-21, бюджет (2.3.16) |
| TURN-MIG / TURN-EDU / TURN-BIZ | Миграция увеличивает Население → растёт потребность в жилье, падает Обеспеченность кв. метрами. Бизнес открывает и закрывает фирмы → меняется потребность в бизнес-площадях. После каждого хода KPI градостроя пересчитываются. | F-URB-10, F-URB-11, F-URB-14 |
| TURN-URB | Игрок выкупает территорию, передаёт землю под застройку, реконструирует ветхий фонд, передаёт помещения образованию, двигает SL-06 и SL-07. Сразу после хода считаются новые площади, стоки, цена метра, доступность и KPI, списываются субсидии. Затем пересчёт города. | F-URB-01…F-URB-21 |
| TURN-TRN / TURN-TUR | Транспорт читает структуру жилого фонда (Индекс плотности застройки), туризм – отельные площади. KPI градостроя пересчитываются после их ходов. | Выходы F-URB-08, F-URB-09 |
| END | Итоговый пересчёт после хода туризма, итоговые KPI в график UI-12. | F-URB-12…F-URB-19 |
| t+1 | Доступность недвижимости t влияет на Миграционную привлекательность в ходе миграции t+1. Помещения, переданные образованию в t, доступны для застройки в ходе образования t+1. Удовлетворение бизнеса по типам застройки фильтрует открытие бизнесов в ходе бизнеса t+1 (F-BIZ-07). | Выходы F-URB-06, F-URB-13, F-URB-19 |

## **Инструменты**

Каждый инструмент описан одним блоком: пользовательская история, описание, поведение в интерфейсе, что уходит в модель и сценарии проверки. Поведение, общее для всех инструментов, описано один раз в общем контракте; в блоках инструментов – только отличия.

Сценарии записаны на Gherkin: ключевые слова на английском, текст шагов на русском, числа в Examples эталонные. Теги: @turn-urb (ход градостроя), @round-start, @round-end, @formula, @kpi, @inflation, @ui, @event, @recalc, @cross-committee.

### **Общий контракт инструментов**

Инструменты двух видов: поп-апы с кнопкой «Применить» (И-10…И-12, И-19) и слайдеры на игровом экране без кнопки (SL-06, SL-07). Правила совпадают с контрактом миграции; ниже – отличия градостроя.

|  |  |  |
| :-: | :-: | :-: |
| \*\*Событие\*\* | \*\*Что происходит\*\* | \*\*Что не происходит\*\* |
| Открытие поп-апа | Ручки стоят на значениях, уже примененных в этом ходу (в начале хода – на нуле). Максимумы считаются от остатка бюджета (И-10, И-19), от доступной земли (И-11, И-12) и от ветхого фонда (И-19). | – |
| Движение ручки | Пересчитываются предикты и итоговая стоимость (или итоговая земля) по всем ручкам поп-апа. | Бюджет и земля не списываются, модель города не пересчитывается |
| Ресурс больше остатка | Ручка не заходит дальше максимума. «Недостаточно бюджета» (UI-32) – по R-06.4. Для И-11/И-12 – то же состояние с текстом «Недостаточно свободной земли» | – |
| «Применить» | Бюджет и земля проверяются заново. Значения записываются, деньги списываются (И-10, И-19), земля резервируется (И-11, И-12), строка в «Документооборот». Поп-ап закрывается. | Модель города не пересчитывается |
| Повторное открытие в том же ходу (R-04) | Ручку можно сдвинуть только вверх от примененного. | Уменьшить или отменить примененное нельзя, деньги и земля не возвращаются |
| «Отмена» или крестик | Ручки возвращаются к примененным значениям, поп-ап закрывается. | – |

### **Ветшание в START**

В START каждого раунда, включая первый, 0,05% жилой площади каждого типа (от итога t−1) уходит в ветхий фонд. Поэтому в ходе градостроя этого же раунда ветхий фонд уже можно реконструировать или передать. Бизнес-площади не ветшают.

### **Расчёт хода градостроя (TURN-URB)**

Порядок по зафиксированным значениям:

1.  Территория: Общая площадь += выкуп; Свободная −= переданная земля; Застроенная += переданная земля (F-URB-01).
2.  Новые жилые и бизнес-площади по типам (F-URB-03, F-URB-04).
3.  Ветхий фонд: − реконструкция, − переданное образованию (F-URB-05, F-URB-06).
4.  Стоки площадей по типам (F-URB-07, F-URB-08) и структура фонда (F-URB-09).
5.  Показатель стандартов → Качество жилья и Коэффициент стандартов (F-URB-15).
6.  Обеспеченность → Коэффициент дефицита → Цена кв. м → Благополучие застройщиков (F-URB-14, F-URB-16, F-URB-17).
7.  Показатель субсидирования → списание → Эффективная цена → Доступность (F-URB-18, F-URB-19).
8.  KPI (F-URB-12…F-URB-15, F-URB-19), затем пересчёт города (R-08).

### **F-URB-12. Удовлетворение потребности бизнеса в площадях (3.4.2.1), KPI**
