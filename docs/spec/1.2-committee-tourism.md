## **Общие правила**

|  |  |
| :-: | :-: |
| \*\*ID\*\* | \*\*Правило\*\* |
| R-01 | \*\*Какое значение читает формула.\*\* Формула берёт последнее посчитанное значение показателя на момент расчёта. Туризм ходит последним и видит итоги ходов всех комитетов текущего раунда. Явная пометка «(раунд t−1)» – итог прошлого раунда, не меняется в течение текущего. В раунде 1 вместо t−1 используются стартовые значения. |
| R-02 | \*\*Когда считается ход.\*\* Расчёт хода выполняется сразу после завершения хода, затем пересчёт города (R-08). |
| R-03 | \*\*Время хода.\*\* 1,5 минуты по умолчанию (меняется на экране настройки партии у ведущего). |
| R-04 | \*\*«Применить» окончательно.\*\* Деньги списываются, значение записывается, в «Документооборот» добавляется строка. Примененное решение в этом ходу нельзя уменьшить или отменить, можно докупить сверх него: ручка или кликер двигается только вверх, разница оплачивается как новая покупка. |
| R-05 | \*\*Таймер хода истёк.\*\* Непримененные изменения в открытых поп-апах сбрасываются, примененное остаётся. |
| R-06.1 | \*\*Бюджет хода общий для всех инструментов комитета.\*\* Доступный остаток = бюджет комитета на начало хода − стоимость решений, уже примененных в этом ходу − стоимость текущих значений инструментов, которые оплачиваются в конце хода и не имеют кнопки «Применить» (у туризма – SL-11). Значения, которые выбраны, но не применены, остаток не уменьшают. |
| R-06.2 | \*\*Максимум инструмента.\*\* Нельзя выбрать значение дороже, чем позволяет остаток. Если в одном окне несколько элементов, их выбранные значения считаются вместе. |
| R-06.3 | \*\*Остаток уменьшился.\*\* Если остаток уменьшился из-за действия в другом окне или из-за SL-11, максимумы во всех открытых окнах пересчитываются. Выбранное сверх максимума игра уменьшает сама: сначала значение, измененное последним, затем предыдущие. Не ниже примененного в этом ходу (R-04). Игрок видит подсказку, ошибка не показывается. |
| R-06.4 | \*\*«Недостаточно бюджета» показывается, когда:\*\* 1) игрок сам тянет инструмент дальше доступного (там, где шкала шире максимума, – SL-11, «+» кликера); 2) игрок меняет параметр, от которого зависит цена, и стоимость выбранного становится больше остатка; 3) остатка не хватает на минимальную единицу (один уровень мероприятия). |
| R-06.5 | \*\*Инструменты с оплатой по факту в конце хода.\*\* У комитета по туризму таких инструментов нет. |
| R-06.6 | \*\*Совместные инвестиции И-09 / И-14 / И-17\*\* – исключение к R-06.2–R-06.5 (спецификации бизнеса и транспорта). Предложение отправляется без проверки бюджета получателя и до принятия ничего не списывает. Если получатель не ответил до END раунда, предложение сгорает: P-13 закрывается, ничего не списывается, у инициатора уведомление «отклонено (истекло)». После принятия каждая сторона обязана оплатить свою долю полной индексированной стоимости. Доля инициатора списывается сразу при принятии, доля партнёра – в начале его ближайшего собственного хода. Списывается min(доступный остаток; непогашенная доля), остаток долга переносится на следующие раунды до погашения, бюджет не уходит в минус. Строительство создаётся один раз при принятии, объект вводится в START(t+1) независимо от долга. |
| R-07 | \*\*Слайдеры на игровом экране (SL-11, SL-12).\*\* Без «Применить», в течение хода двигаются в обе стороны, значение фиксируется, а стоимость списывается по завершении хода. Платный SL-11 уменьшает остаток своим текущим положением сразу. |
| R-08 | \*\*Пересчёт города\*\* после хода каждого комитета, в START каждого раунда после события и инфляции (события – с раунда 2; в раунде 1 – после стартового снимка S0, R-GEN-04) и итоговый в END. Идемпотентен: значения t считаются от сохраненных итогов t−1 и решений раунда; стоки (ТТБ, отели) не прибавляются повторно, случайные значения не перебрасываются. «Применить» показатели не меняет. Иконка изменения KPI сравнивает с итогом прошлого раунда, точка графика UI-12 – только по итогу раунда. Освоение миграционного потенциала фиксируется в расчёте хода миграции по пропускной способности из пересчёта START |

  

## **Правила комитета по туризму**

|  |  |
| :-: | :-: |
| \*\*ID\*\* | \*\*Правило\*\* |
| R-TUR-01 | \*\*Туризм до своего хода .\*\* До расчёта хода туризма в раунде t цепочка турпотока (F-TUR-01…F-TUR-12) пересчитывается при каждом пересчёте города по текущим входам других комитетов, эффектам событий раунда t и \*\*решениям туризма раунда t−1\*\* (уровни мероприятий, Показатель туристической рекламы, Туристический сбор). Стоки (Потенциальное кол-во ТТБ, Отели) до хода туризма берутся из итога t−1 и не меняются. После хода туризма t – по решениям раунда t. Аналог R-URB-03. |
| R-TUR-02 | \*\*Одно-раундовые инструменты.\*\* В START раунда t+1 кликеры И-15, слайдеры И-16 и SL-11 возвращаются в 0. SL-12 «Туристический сбор» сохраняет положение между раундами. |
| R-TUR-03 | \*\*Стоки меняются только в расчёте хода туризма.\*\* Новые и закрытые ТТБ, новые и закрытые отели считаются ровно один раз в TURN-TUR. Повторные пересчёты их не трогают. Промежуточные значения дробные, итоговые стоки округляются один раз (как R-BIZ-05). |
| R-TUR-04 | \*\*ТТБ – часть торговых бизнесов.\*\* Если в раунде число торговых бизнесов уменьшилось (закрытия в TURN-BIZ, события на сток), Потенциальное кол-во ТТБ (t−1) в расчёте хода туризма умножается на Торговые (t) / Торговые (t−1), если это отношение меньше 1. Торговые (t−1) – итог прошлого раунда до среза событием, поэтому срез в START тоже уменьшает базу ТТБ. События на сток бизнесов отели не затрагивают (R-BIZ-06). |
| R-TUR-05 | \*\*Доход от сбора – в следующем раунде.\*\* Доход от туристического сбора (t) фиксируется в END(t) и один раз зачисляется в бюджет туризма в START(t+1). Городская половина сбора входит в Налоговые сборы (t). Прогноз дохода не увеличивает остаток текущего хода. |
| R-TUR-06 | \*\*Эффекты мероприятий для других комитетов – в t+1.\*\* Места культурных и развлекательных мероприятий образование читает по уровням t−1 (F-EDU-15). Бонус от бизнес-мероприятий бизнес читает по уровням t−1, в раунде t решения туризма t на Инвестиционную привлекательность не влияют. |
| R-TUR-07 | \*\*Пандемия и KPI «Относительный турпоток».\*\* Пока активен E-01, KPI «Относительный турпоток» в BLK-04, P-10.29, оценке и графике UI-12 равен итогу прошлого раунда (до срабатывания события). Модель города и другие комитеты (Социальная напряжённость, миграция, транспорт, экономика) используют фактическое значение раунда с множителем события. |
| R-TUR-08 | \*\*Индексируемые пределы.\*\* Предельный туристический сбор = 2 000 ₽ (инд.), Максимум рекламного насыщения = Абсолютный турпоток (t−1) × 1 000 ₽ (инд.). Положение SL-12, выбранное игроком, не индексируется. |

  

## **Место комитета в раунде**

Туризм ходит последним: в его ход уже известны население, обеспеченность досугом, торговые бизнесы, отельные площади и транспортные ворота текущего раунда. «Применить» только фиксирует значения и списывает деньги. Сразу после хода считаются сезонность, привлекательность, турпоток, новые ТТБ и отели, выручка туристического бизнеса и KPI, затем итоговый пересчёт города (END). Новые и закрытые ТТБ и отели (F-TUR-13, потенциальное кол-во ТТБ в F-TUR-14, F-TUR-15) считаются только в расчёте хода туризма (R-TUR-03); в пересчёте города (шаг 10 конвейера) цепочка туризма читает их последнее значение и считает только потоки. Обеспеченность КДМ и индекс внешней связности считаются раньше (шаги 7 и 8), поэтому туризм читает их текущие значения. Решения туризма раунда t другие комитеты почувствуют в раунде t+1.

|  |  |  |
| :-: | :-: | :-: |
| \*\*Фаза\*\* | \*\*Что происходит\*\* | \*\*Формулы\*\* |
| START | Срабатывает событие, с раунда 2 (E-01 режет турпоток вдвое). Считаются инфляция раунда и Коэффициент инфляции (t), с ним цены мероприятий и нормы субсидий. Комитет получает бюджет + доход от сбора t−1. И-15, И-16, SL-11 = 0. Затем пересчёт города, в том числе в раунде 1 (после стартового снимка S0, R-GEN-04): цепочка туризма считается по решениям t−1 (R-TUR-01). | F-TUR-21, F-TUR-22, бюджет (2.3.16) |
| TURN-MIG | Миграция читает Абсолютный турпоток для туристов, готовых переехать (F-MIG-03); Относительный турпоток входит в Социальную напряжённость (F-MIG-13). | Выходы F-TUR-06, F-TUR-12 |
| TURN-EDU | Обеспеченность культурно-досуговыми мероприятиями меняет Туристическую привлекательность. | Вход F-TUR-04 |
| TURN-BIZ | Число торговых бизнесов меняет потолок и базу ТТБ; Эффективность бизнеса – выручку. | Входы F-TUR-13, F-TUR-18/19 |
| TURN-URB | Отельные площади – фильтр земли для новых отелей. | Вход F-TUR-15 |
| TURN-TRN | Аэропорты и пассажирские порты (введённые), разводные мосты – транспортная доступность и привлекательность. | Входы F-TUR-02, F-TUR-04 |
| TURN-TUR | Игрок назначает мероприятия (И-15), субсидии (И-16), рекламу (SL-11), сбор (SL-12), готовит совместные инвестиции (И-17). Сразу после хода – расчёт хода F-TUR-01…F-TUR-20. | F-TUR-01…F-TUR-20 |
| END | Итоговый пересчёт, отток, гении, фиксация KPI и дохода от сбора (t). | F-TUR-18, F-TUR-20 |
| t+1 | Образование получает места мероприятий, бизнес – бонус бизнес-мероприятий, транспорт – Абсолютный турпоток (t−1) для пассажиропотока и доходов, доход от сбора зачисляется в бюджет. | Выходы F-TUR-09, F-TUR-20 |
