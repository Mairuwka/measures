Компоненты в ките – отдельные фреймы с суффиксом состояния, а не варианты одного компонента. Состояние в коде \= суффикс после «/»: initial, hover, pressed, error, disabled и специальные (min, max, choosen, left и т. д.).

## **Общие правила**

| ID | Правило |
| :---- | :---- |
| R-UI-01 | **Порядок состояний** у интерактивных элементов: initial → hover → pressed (у полей typing, у выбора selected / choosen) → error → disabled. Так задано в общих правилах Figma. |
| R-UI-02 | **Наведение.** hover включается, когда курсор над элементом, и выключается, когда курсор ушел. У disabled состояния hover нет, курсор not-allowed. |
| R-UI-03 | **Нажатие.** pressed включается по нажатию кнопки мыши и держится, пока кнопка зажата. Действие срабатывает при отпускании над тем же элементом. Отпустили за пределами – действия нет, элемент возвращается в initial. |
| R-UI-04 | **Выбор.** Чипы-вкладки, карточки и переключатели после клика остаются в pressed / choosen, пока выбор не сменится. Это состояние «выбрано», а не «нажато». |
| R-UI-05 | **Ошибка.** error добавляет под элементом строку сообщения (text\_wrapper «Текст ошибки», Pixel Code 13 px, \#F52538). Высота элемента растет на 25 px (у Input на 29,4 px, у карточки комитета на 33 px), соседние элементы сдвигаются, а не перекрываются. |
| R-UI-06 | **Блокировка.** disabled не реагирует на наведение, клик и клавиатуру.  |
| R-UI-07 | **Размер.** У чипов pressed увеличивает размер с 266 × 47 до 270,4 × 51,4 px. Соседние элементы при этом не прыгают: место под увеличение заложено в отступах группы. |
| R-UI-08 | **Анимации.** Смена состояний мгновенная или с затуханием до 150 мс. Других анимаций интерфейса нет. |
| R-UI-10 | **Базовое разрешение** 1920 × 1080, только десктоп. При другом размере окна макет масштабируется целиком с сохранением пропорций. |
| R-UI-11 | **Числа** форматируются по 4.2.8.1 дополнения ТЗ Дизайн: деньги, люди, доли, коэффициенты, баллы. |
| R-UI-12 | **Длинные тексты.** Названия команд и имена до 64 символов переносятся, а не обрезаются. Где места нет (теги UI-22, строки лидерборда), текст обрезается с «…» и полным текстом в тултипе. |

## **Поведение компонентов**

Каждая группа компонентов описана одним блоком: компоненты и где они используются, поведение по состояниям и сценарии проверки. Сценарии записаны на Gherkin: ключевые слова на английском, текст шагов на русском. Общие правила R-UI-01…R-UI-12 здесь не повторяются.

#### **Поведение**

| Состояние | Когда | Что дальше |
| :---- | :---- | :---- |
| initial | Кнопка доступна, курсора нет | – |
| hover | Курсор над кнопкой | Уход курсора → initial |
