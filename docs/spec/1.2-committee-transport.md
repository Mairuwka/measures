# **Обозначения**

|  |  |
| :-: | :-: |
| \*\*Термин\*\* | \*\*Значение\*\* |
| \*\*t / t−1 / t+1\*\* | Текущий раунд / зафиксированное состояние прошлого раунда / следующий раунд. |
| \*\*START\*\* | Начало раунда: эффект события, индексация, бюджеты; затем городской пересчет, в том числе в раунде 1 (после стартового снимка S0, R-GEN-04; событий в раунде 1 нет), согласно R-08 спецификаций.  |
| \*\*TURN-TRN\*\* | Ход транспорта (после миграции, образования, бизнеса, градостроительства); завершение решений, их однократная обработка, затем пересчёт города. |
| \*\*END\*\* | Конец раунда: износ дорог, фиксация сальдо/рядов/снимка t; однократные операции города. |
| \*\*(инд.)\*\* | Денежная норма в ценах раунда 1, индексируется один раз коэффициентом инфляции t. |

| \*\*И-13, И-14, И-18; P-05, P-09, P-07\*\* | Поп-апы общественного транспорта, инфраструктурных вложений и строительства мостов. |
| \*\*SL-08, SL-09, SL-10\*\* | Экранные слайдеры: ремонт, тариф, дороги/развязки. |
| \*\*KPI / сток / поток\*\* | Оцениваемый показатель / накопительное состояние / вычисление за раунд. |

# **Общие правила**

|  |  |
| :-: | :-: |
| \*\*ID\*\* | \*\*Правило\*\* |
| \*\*R-01\*\* | Какое значение читает формула. Формула берёт последнее посчитанное значение показателя на момент расчета. Пример: комитет по градостроительству в свой ход видит Население, уже пересчитанное после хода миграции. Если в формуле явно стоит «(раунд t−1)», это итог прошлого раунда, зафиксированный в его конце; он не меняется в течение текущего раунда. В раунде 1 вместо значений t−1 используются стартовые. |
| \*\*R-02\*\* | Когда считается ход. Расчёт хода комитета (формулы, зависящие от его решений) выполняется сразу после завершения его хода, а не в конце раунда. Сразу после расчёта хода – пересчёт города (R-08). |
| \*\*R-03\*\* | Время хода. 1,5 минуты по умолчанию (может быть изменено на экране настройки партии у ведущего) |
| \*\*R-04\*\* | «Применить» окончательно. После «Применить» деньги списываются, значение записывается, в «Документооборот» добавляется строка. В этом ходу примененное решение нельзя уменьшить или отменить, деньги не возвращаются. Можно применить новое решение сверх него (докупить): ручка двигается только вверх от примененного значения, разница оплачивается как новая покупка. Исключение – адаптация мигрантов: «Применить» фиксирует долю, а сумма списывается в расчете хода по фактическому пулу. |
| \*\*R-05\*\* | Таймер хода истёк. Изменения, выставленные в открытых поп-апах, но не примененные, сбрасываются. Примененное остаётся. |
| \*\*R-06.1\*\* | Бюджет хода общий для всех инструментов комитета. Доступный остаток = бюджет комитета на начало хода − стоимость решений, уже примененных в этом ходу − стоимость текущих значений инструментов, которые оплачиваются в конце хода и не имеют кнопки «Применить». Значения, которые выбраны, но не применены, остаток не уменьшают. |
| \*\*R-06.2\*\* | Максимум инструмента. Нельзя выбрать значение инструмента дороже, чем позволяет остаток. Если в одном окне несколько инструментов, их выбранные значения считаются вместе: общая стоимость не может превышать остаток. |
| \*\*R-06.3\*\* | Остаток уменьшился. Если остаток уменьшился из-за действия в другом окне или из-за другого инструмента, максимумы бюджета, который можно выделить, во всех открытых окнах пересчитываются. Если выбранные значения перестали помещаться в остаток, игра сама уменьшает их до допустимых: сначала значение, измененное последним, затем предыдущие, пока общая стоимость не поместится. Значения не уменьшаются ниже уже примененных в этом ходу (R-04). Игрок видит подсказку, что выбранное значение уменьшено, ошибка не показывается |
| \*\*R-06.4\*\* | Сообщение «Недостаточно бюджета» показывается, когда:игрок сам пытается выбрать значение дороже остатка (это возможно там, где шкала инструмента шире доступного максимума);игрок меняет параметр, от которого зависит цена (например, уровень), и стоимость выбранного значения становится больше остатка. Выбранное значение при этом не меняется, и применить решение нельзя, пока игрок сам его не уменьшит;остатка не хватает даже на минимальную единицу инструмента |
| \*\*R-06.5\*\* | Инструменты с оплатой по факту в конце хода. Это инструменты, стоимость которых зависит от данных, известных только после хода. Их максимум считается по текущим данным так же, как в пункте 2, и уменьшается по пункту 3. Примененное значение остаток не уменьшает, а стоимость списывается по завершении хода по фактическим данным. Если к этому моменту денег не хватает, значение урезается пропорционально доступной сумме. |
| \*\*R-06.6\*\* | Совместные инвестиции И-09 / И-14 / И-17 — согласованное исключение к R-06.2–R-06.5. Инициатор отправляет предложение без проверки бюджета комитета-получателя. До принятия предложение не создает затрат, задолженности или строительства; если получатель не ответил до END раунда, предложение сгорает так же без последствий (P-13 закрывается, у инициатора «отклонено (истекло)»); отказ до принятия также ничего не списывает. После принятия предложение превращается в обязательство каждой команды оплатить свою фиксированную долю полной индексированной стоимости. Строительство начинается СРАЗУ после ПРИНЯТИЯ предложения, даже при 0 ₽ текущей оплаты: создается одна запись «строится» по ID сделки, независимо от графика платежей. Доля инициатора подлежит оплате сразу; доля партнёра — в начале его ближайшего собственного хода. В каждый предусмотренный момент платежа списывается min(доступный остаток собственного бюджета команды; её непогашенная доля). Неоплаченная часть переносится на следующий раунд; если снова денег недостаточно, списывается доступная часть и остаток переносится дальше, сколько потребуется раундов вплоть до полного погашения, включая раунды с нулевой оплатой. Долг не превращать в отрицательный бюджет, не урезать номинал инвестиции, не возвращать уже оплаченные части и не покрывать чужую долю автоматически; стоимость принятой сделки повторно не индексировать. Одну сделку, объект и платёж не создавать и не списывать повторно при R-08-пересчете. Не путать начало строительства с вводом в эксплуатацию:  объекты совместных сделок И-14 вводятся один раз в START(t+1) после принятия в раунде t, даже если долг не погашен; отдельные стадии строительства по раундам не инкрементировать. Остальные обычные инструменты транспорта (И-13, И-18, самостоятельные покупки И-14, SL-08 и SL-10) подчиняются общим ограничениям R-06.1–R-06.5. |
| \*\*R-07\*\* | Слайдеры на игровом экране (SL-xx). У них нет кнопки «Применить». В течение хода ручка свободно двигается в обе стороны, запрет на уменьшение (R-04) к ним не относится. Значение фиксируется, а стоимость списывается по завершении хода. Платные слайдеры уменьшают остаток бюджета своим текущим положением сразу (R-06). |
| \*\*R-08\*\* | Пересчёт города. После хода каждого комитета выполняется расчёт хода, а затем пересчёт города: все общие показатели и KPI всех комитетов считаются заново по текущему состоянию. Пересчет выполняется и в начале каждого раунда, после случайного события (события – с раунда 2), в том числе в раунде 1: перед ним считается стартовый снимок S0 (R-GEN-04). В конце раунда, после хода комитета по туризму, – итоговый пересчет и шаги, которые выполняются раз в раунд: отток жителей (2.3.1), бросок по гениям (2.3.20), фиксация итогов для графиков и сравнения раундов. Население и мигранты окончательны сразу после хода миграции. Пересчёт можно повторять сколько угодно раз с тем же результатом: значения раунда t каждый раз считаются от сохраненных итогов t−1 и решений раунда, случайные значения не разыгрываются заново. Во время хода «Применить» показатели не меняет. Иконка роста или падения KPI сравнивает текущее значение с итогом прошлого раунда; точка на графике по раундам (UI-12) появляется только по итогу раунда. Освоение миграционного потенциала фиксируется в расчёте хода миграции по пропускной способности из пересчёта START |
| \*\*R-TRN-01\*\* | Эксплуатационные доходы и расходы — потоки раунда; содержание новых мест И-13 и мостов И-18 начинается после TURN-TRN(t), объектов/грузовых дорог И-14 — после START(t+1), не списывается повторно при R-08. Сальдо(t) фиксируется в END(t) и единожды учитывается в START(t+1). |
| \*\*R-TRN-02\*\* | События никогда не модифицируют KPI напрямую: E-01 изменяет грузооборот бизнеса и турпоток, влияющие на транспортные расходы и доходы косвенно. |

# **Место комитета в раунде**

Очерёдность: миграция → образование/культура → бизнес → градостроительство → транспорт → туризм. В TURN-TRN транспорт видит результаты миграции, образования, бизнеса и градостроительства текущего раунда, уже доступные после их пересчета. Турпоток в формулах, явно содержащих t−1, читается из сохраненного прошлого раунда, несмотря на более поздний ход туризма. Индекс внешней связности (F-TRN-06) в пересчёте города считается в шаге 8 конвейера, до цепочки туризма. Остальные формулы транспорта в пересчёте считаются в шаге 17 в таком порядке: спрос, плотность и нуждающиеся в ОТ (F-TRN-01); автомобилисты по сохранённой доле и пассажиропоток (F-TRN-04); распределение грузов и городской остаток (F-TRN-12, первая часть); дорожный трафик (F-TRN-11); загруженность дорог и мостов (F-TRN-09); проходимость и обработанный грузооборот (F-TRN-12, вторая часть), F-TRN-13, F-TRN-14; доходы и содержание (F-TRN-17…F-TRN-19); доля финансирования содержания ОТ и сальдо (F-TRN-20); эффективная вместимость ОТ (F-TRN-05); «Нагрузка на ОТ» (F-TRN-08) и «Обеспеченность ОТ» (F-TRN-07); свободная пропускная способность (F-TRN-16); бонус транспортной инфраструктуры (F-TRN-15) – последним, до инвестиционной привлекательности бизнеса (шаг 18). Круга нет: доля финансирования зависит от доходов и расходов, но не от нагрузки. Целевая и новая доля автомобилистов (F-TRN-02, F-TRN-03) считаются только в расчёте хода транспорта.
