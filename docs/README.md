## Секции проверки (справа от экранов)

На странице «Экраны для согласования» справа от секций 00–08 лежат копии для проверки дизайнером и сверки с ТЗ: **09** — экраны одиночной игры целиком, **10** — экраны командной игры целиком (списки с прокруткой развёрнуты), **11** — все поп-апы в полную высоту, у P-11 — каждая вкладка отдельным окном. Это копии: правки делаются на исходных экранах, затем секции пересобираются скриптами (порядок — в [figma-howto.md](figma-howto.md)). Страница «Динамический интерфейс» больше не поддерживается и может быть удалена.

## История

- До Figma экраны собирались HTML-генератором: `screens/mayor-screens.html` (111 экранов), исходники в `screens/generator/`. Это черновой прогон, источник истины теперь Figma.
- `figma-plugin/px-to-pixelcode/` — локальный плагин Figma: возвращает шрифт Pixel Code текстовым слоям с префиксом `px·` (если такие появятся).
- Ревью-документы с правками Claude к ТЗ: [первый прогон](https://docs.google.com/document/d/1CT7xs9-O3FFVSK3Lid-9NcX9nLGdAYsaQKQmiXfCyk8/edit), [второй](https://docs.google.com/document/d/1lQ8MAQay5GJsYoyNSuEGYD2hrMUwbae8tZtGY2vokQc/edit), [третий](https://docs.google.com/document/d/1iOwlUpQ_-G7JYButGsDnLJBQ4st1ZF74nsG-YG7mN_I/edit).
