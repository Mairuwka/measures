# Переносы строк в интерфейсе — правила для разработки

Макеты «Экраны для согласования» в Figma уже свёрстаны по этим правилам: переносы в строках показателей расставлены вручную неразрывными символами. В коде перенос делает браузер, поэтому без этих правил те же строки снова разорвутся неправильно. Здесь записано, что нужно повторить.

## Где это нужно

Везде, где подпись может уйти на вторую строку. Чаще всего это строки показателей (компоненты metN / metUp / metDown: подпись слева, значение и бейдж справа) в поп-апах И-01…И-19, P-10, P-11, P-13. Также длинные подписи в бейджах, кнопках и примечаниях.

## Правила

1. **Единица измерения не отрывается от последнего слова.** Пробел после последней запятой перед единицей неразрывный, пробелы внутри единицы тоже.
   `площадях, кв. м` → `площадях, кв. м`. Тогда на вторую строку уходит «площадях, кв. м» целиком, а не одна «м» или «%».
   Единицы: `%`, `п.п.`, `чел.`, `ед.`, `шт.`, `₽`, `₽/кв. м`, `кв. м`, `км`, `авто-экв./сут.`, `×`, `баллов`.
2. **Предлог или союз переносится вместе со следующим словом.** После коротких служебных слов ставится неразрывный пробел: без, в, во, с, со, на, по, и, к, ко, о, об, от, до, для, за, из, у, не, при, над, под, через, а, или, между.
   `мигранты без образования` → `мигранты без образования`.
3. **Скобка до 40 символов не разрывается.** Все пробелы внутри неё неразрывные: `(с учетом субсидии)`. Если скобка не помещается в строку, она целиком уходит на следующую.
4. **Устойчивые сочетания не разрываются:** «прошлого раунда», «этого раунда», «этом раунде», «следующего раунда», «начала игры».
5. **Сокращение с точкой (2–5 букв) держится вместе со следующим словом:** `общ. транспорт`, `тур. бизнес`, `кв. м`.
6. **Нет разрыва после «/» и дефиса.** Браузер, как и Figma, может перенести строку после «/» или «-». После них ставится word joiner `⁠`: `₽/⁠кв. м`, `авто-⁠экв./⁠сут.`, `кол-⁠во`, `it-⁠специалисты`.
7. **Число не отрывается от единицы, тире — от предыдущего слова.** `40 %`, `1 200 чел.`, `8,00 млрд ₽`, `грузовой порт × 1`, `чел. – 1,20 млрд ₽` (тире остаётся в конце строки, а не в начале следующей). Это касается и ленты «Документооборот».
8. **Нет разделителей « · ».** Несколько значений не пишутся в одну строку через точку. Каждое значение — отдельная строка показателя, примечания разбиваются переносом строки (`\n`).
9. **Если подпись всё равно не помещается так, как нужно,** формулировку правят вместе с дизайном. Сокращения (`пром.`, `ЦСИ`) не используются, названия пишутся целиком.

## Как сделать в коде

Удобнее всего одна функция форматирования подписей, через которую проходят все тексты показателей (и данные, и словари):

```ts
const NBSP = ' ';
const WJ = '⁠';
const PREP = new Set(['без','в','во','с','со','на','по','и','к','ко','о','об','от','до','для','за','из','у','не','при','над','под','через','а','или','между']);
const UNIT = /^(%|п\.п\.|чел\.|ед\.|шт\.|₽|₽\/кв\. м|кв\. м|км|авто-экв\.\/сут\.|×|баллов)$/;
const PHRASES = ['прошлого раунда', 'этого раунда', 'этом раунде', 'следующего раунда', 'начала игры'];

export function nowrapLabel(s: string): string {
  let t = s.replace(/\(([^()]{1,40})\)/g, m => m.replace(/ /g, NBSP));                 // 3
  for (const p of PHRASES) t = t.replace(new RegExp(p, 'gi'), m => m.replace(/ /g, NBSP)); // 4
  t = t.replace(/(^|\s)([А-Яа-яЁё]{2,5}\.) (?=[А-Яа-яЁё])/g, (_, a, b) => a + b + NBSP);   // 5
  t = t.split(' ').map((w, i, a) => i < a.length - 1 && PREP.has(w.toLowerCase()) ? w + NBSP : w + ' ')
       .join('').trimEnd().replace(new RegExp(NBSP + ' ', 'g'), NBSP);                       // 2
  const m = t.match(/^(.*\S),[  ]([^,]+)$/);
  if (m && UNIT.test(m[2].replace(/ /g, ' '))) t = `${m[1]},${NBSP}${m[2].replace(/ /g, NBSP)}`; // 1
  return t.replace(/([/-])(?=\S)/g, '$1' + WJ);                                              // 6
}
```

Дополнительно в CSS у подписей: `hyphens: manual; overflow-wrap: normal; word-break: normal;`. Автоматические переносы по слогам отключены, браузер переносит только по пробелам.

## Строка документооборота (UI-24, BLK-03)

У строки два состояния, его выбирают по числу строк текста после переноса:
- **текст в одну строку:** высота строки по содержимому (52 px), номер раунда, тег команды и текст выровнены по вертикальному центру;
- **текст в 2–3 строки:** высота по тексту, номер раунда и тег прижаты к верху и стоят на уровне первой строки.

Текст не обрезается многоточием, а переносится (ТЗ 1.4, BLK-03).

## Проверка

Перед сдачей экрана — пройти поп-апы P-10 / P-11 и инструменты И-xx на ширине окна 800 px и убедиться:
- ни одна строка не начинается с единицы, «%», «м» или закрывающей скобки;
- ни одна строка не заканчивается предлогом;
- нигде нет « · ».
