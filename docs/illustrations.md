## Особенности

- Обводка жителя на S-10 (белая — реплика открыта, розовая — новая реплика, нет — прочитано) — отдельный слой `stroke` с картинкой силуэта (расширенная альфа персонажа). Для нового жителя силуэт нужно сгенерировать заново (PIL: альфа → порог → MaxFilter 13 → заливка цветом).
- Фон города в Figma — статичная картинка этапа; GIF через MCP не проигрывается.
