# Симулятор мэра — материалы к макетам

- `fonts/PixelCode/` — исходный шрифт интерфейса Pixel Code (Bold, Medium, Regular), лицензия SIL OFL 1.1 (`OFL-LICENSE.txt`). Источник: github.com/qwerasd205/PixelCode.
- `figma-plugin/px-to-pixelcode/` — локальный плагин Figma «px → Pixel Code». Экраны собираются через Figma API на сервере, где шрифта Pixel Code нет, поэтому надписи Pixel Code собраны из точных контуров этого шрифта (фреймы `px·<размер>·<текст>`). Плагин заменяет их живым текстом Pixel Code Bold с теми же размером, межстрочным, трекингом, цветом, обводкой, тенью и местом в автолейауте.
- `figma-build/` — библиотека сборки экранов в Figma: `lib.js` (контуры Pixel Code, текст, модальные окна), `lib2.js` (составные элементы поп-апов), `lib3.js` (данные комитетов и сборка S-08), `lib4.js` (поп-апы инструментов), `lib5.js` (поп-апы показателей P-10), `lib6.js` (лидерборд, документооборот, экран ведущего и съезда), `lib7.js` (наблюдение, P-04, P-14, P-17, приёмная S-10, итоги S-11, график UI-12), `glyphs.json` (контуры глифов из `PixelCode-Bold.ttf`). Копии библиотек хранятся текстовыми слоями на служебной странице «_build · служебная» в Figma.

## Как вернуть живой текст Pixel Code

1. Установите `fonts/PixelCode/PixelCode-Bold.ttf` в систему и перезапустите Figma desktop.
2. В Figma откройте Plugins → Development → Import plugin from manifest… и выберите `figma-plugin/px-to-pixelcode/manifest.json`.
3. Откройте страницу «Экраны для согласования» и запустите плагин. Если что-то выделено, он обработает только выделение, иначе всю страницу.

## Экраны на согласование

- `screens/mayor-screens.html` — все экраны, состояния и поп-апы по ТЗ (111 фреймов 1920×1080), шрифты Pixel Code и Inter. Открывается в браузере; клик по фрейму открывает его в полный размер.
- `screens/generator/` — генератор страницы (Python): `python3 screens/generator/build.py` пересобирает HTML. Контент — в `data.py`, компоненты — в `ui.py`, стили — в `css.py`.
